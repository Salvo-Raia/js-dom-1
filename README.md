## 🎯 Assignment

Create a simple interactive page using JavaScript and the DOM.

The page must display:

- An image of a **switched-off light bulb**, provided in the exercise attachments.
- A button next to the image with the label **"Turn On"**.

When the user clicks the button, the light bulb must turn on by replacing the original image with the **switched-on light bulb** image, also provided in the attachments.

## ⭐ Bonus - Turn On & Turn Off

Extend the basic functionality to allow the user to switch the light bulb on and off.

The interaction must alternate with each button click:

- **First click:** the light bulb turns on and the button label changes to `"Turn Off"`.
- **Second click:** the light bulb turns off and the button label changes to `"Turn On"`.
- **Subsequent clicks:** the same behavior continues alternately.

To implement this bonus, you may find the JavaScript string method `includes()`.

[MDN - String.prototype.includes()](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/includes)
